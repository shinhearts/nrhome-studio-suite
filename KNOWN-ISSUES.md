# Windows beta notes

- Windows x64 is the first packaged target. More hardware and clean-account testing is needed.
- App data lives in the PC's Windows user profile, even when the suite runs from USB.
- Desktop shortcuts must be recreated after moving the suite folder or changing a USB drive letter.
- nrMONOLOG records and exports WebM/Opus, not WAV. Hotkeys are unassigned until configured and are inactive while their settings dialog is open.
- Emulator setup needs internet on a fresh profile. Streaming services and radio sources can change independently of nrHome.
- Microphone, audio-interface and MIDI behavior depend on the device and OS permissions. Report your setup when a problem occurs.
- The supplied apps do not carry a Windows publisher certificate. A protected-media runtime signature is separate from Windows publisher signing.
