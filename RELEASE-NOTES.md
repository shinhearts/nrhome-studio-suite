# nrHome Studio Suite — Windows Beta 1

**Vibe coded from the heart.** A little more personal computing. A little less noise.

Four retro desktop tools for watching, listening, recording, and making music:

- **nrVIEW 0.29.1-beta.1:** television/media player, video tapes, shelves and homebrew cartridges.
- **nrTUBE 0.2.1-beta.1:** radio receiver, cassette player and tape shelves.
- **nrRACK 0.13.3-beta.1:** floating instruments, effects, MIDI routing, mixing and recording, including granular sampler mode.
- **nrMONOLOG 0.1.1-beta.1:** voice recorder and cassette shelf, corrected resizing, icon-only transport controls and customizable global hotkeys.

Includes four hardware desktop icons and complete Windows x64 runtimes. No Node.js installation or old patches required.

Download Part1, Part2 and Setup-nrHome-Beta-1.cmd into the same folder, then run setup. Both ZIPs share the same folder structure; manual extraction is supported. See SHA256SUMS.txt to verify the downloads.

The beta is free. Optional support is planned; no payment link is active yet. Original development source is not published in this distribution repository. Third-party notices remain included.

Please back up important work and report repeatable issues with app/version, Windows version and device details. Preferences stay on the Windows computer when running from USB. Online services and first-time emulator setup require internet. Protected-service support is not guaranteed.
